# Visual Assets for OpenCutter

This directory contains media assets used in repository documentation (`README.md`, etc.).

### Recommended Visuals

1. **`opencutter-hero-screenshot.png`**:
   - High-resolution screenshot of the OpenCutter web application with calculated cuts.
   - Shows stock sheets table, cut list table, and the resulting interactive SVG diagram.
   - Recommended resolution: ~1600x900px or ~1920x1080px (PNG).

2. **`demo.gif`** (optional):
   - A short (5–10s) animated screen recording showing piece input and real-time cut layout computation.
